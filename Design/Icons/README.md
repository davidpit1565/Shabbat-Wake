# Alternate app icons (planned Pro feature)

`premium-*.png` were cropped from the ChatGPT concept sheet (concepts 01, 02, 04, 06, 07, 08) and upscaled to 1024x1024.
They are **not wired into the app yet** and are low resolution (about 200 px source), so they look soft. Replace each with a native 1024x1024 export when available, keeping the filenames.

The default (free) icon is `App/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`, generated by `Scripts/generate_app_icon.py`.

Wiring them in needs: Pro purchase (StoreKit), alternate icon sets in the asset catalog plus `ASSETCATALOG_COMPILER_ALTERNATE_APPICON_NAMES`, and a Settings picker that calls `UIApplication.setAlternateIconName`.
