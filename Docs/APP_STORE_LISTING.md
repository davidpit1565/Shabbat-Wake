## App Review notes

Shabbat Waker is an alarm clock and Jewish-calendar app. To test:
1. Open the app and allow Alarms, Location and Notifications when asked (Location is optional; alarms work without it).
2. Alarms tab > + > Save. A regular alarm is an Apple system alarm (iOS 26.1 or later is required to create it).
3. Settings > "Test the alarm" schedules an alarm about a minute ahead; lock the phone to see the full-screen alarm.
4. Create an alarm with the "Shabbat alarm" switch on: it is an ordinary notification without buttons whose sound stops by itself. It does not sound if the silent switch is on (stated in the app).
5. Times tab shows candle lighting and havdalah for the current location (from Hebcal.com).
There is no account or login. In version 1.0 all features are available; no purchase is required.
